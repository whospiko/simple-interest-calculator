## About the Project

This project provides a simple script/tool to help users quickly compute simple interest and total accrued amounts. It is ideal for quick financial calculations, educational demonstrations, or basic banking logic implementation.

---

## Formula Used

Simple interest is calculated using the standard formula:

$$A = P \cdot (1 + r \cdot t)$$

Where:
* **$P$** = Principal amount (initial investment or loan amount)
* **$r$** = Annual interest rate (in decimal format, e.g., $5\% = 0.05$)
* **$t$** = Time period (in years)
* **$A$** = Total final amount (Principal + Interest)
